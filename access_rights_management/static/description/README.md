# دليل استخدام Access Rights Management

شرح عربي للموديول بصور من داخل النظام، وفيديو قصير للاستخدام.

| الملف | المحتوى |
|---|---|
| `index.html` | الدليل الكامل — افتحه بأي متصفح |
| `screens/` | ٢٥ صورة من داخل أودو، كل صورة عليها أسهم وشرح مختصر |
| `video/walkthrough.webm` | فيديو ٢:١٤ دقيقة: إنشاء بروفايل كامل ثم جولة على شاشات التدقيق |

## ملاحظات

- الصور والفيديو مأخوذة من قاعدة بيانات `17` على `localhost:8069` بواجهة إنجليزية،
  والشرح كله عربي.
- البيانات المستخدمة في التصوير تجريبية: مستخدمون بأسماء تنتهي بـ `.demo`،
  أقسام (Sales / Accounting / HR / Warehouse)، وبروفايل `Sales Team — Restricted`.
- صيغة الفيديو `webm` — تشتغل في Chrome و Edge و Firefox مباشرة.
