Stock Card Report

The Stock Card Report module provides a detailed overview of product movements (in/out) within a selected location and date range. This module simplifies inventory tracking and reporting, offering both on-screen views and export options in PDF or Excel formats.

Usage

Follow these steps to use the module:

  1. Navigate to Inventory > Reporting > Stock Card.
  2. Select the Start Date, End Date, Products, and Location.
  3. Choose one of the following actions:
    • View: Display the report directly on the screen.
    • Export PDF: Download the report as a PDF file.
    • Export XLSX: Download the report as an Excel file.
    • Cancel: Exit without taking any action.

Permissions

You must grant the required access rights to allow users to use the add-on and generate reports.

Proper permissions must be assigned to the user to enable them to access the Stock Card Report and export results. Without these permissions, users will not be able to utilize the module's features.
