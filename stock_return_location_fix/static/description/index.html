Stock Return to Original Location

Returned goods go back exactly where they came from — the source location of the original delivery, not the operation type’s generic default.

Odoo 17 Odoo 18 Odoo 19 LGPL-3 Community & Enterprise

Why this module?

When you use sub-locations (shelves, zones, branch stores…), a delivery is picked from a specific place — say WH/Stock/Shelf A. But when the customer sends the goods back, the standard return wizard sends them to the return operation type’s default destination (typically the warehouse root WH/Stock, or a configured returns area). The quantity ends up in the wrong place, on-hand per shelf is off, and someone has to make an extra internal transfer to fix it.

This module makes every return created from the Return wizard go back to the source location of the original transfer — on the return picking and on every stock move inside it, so the goods physically land on the right shelf.

How it works (technical)

  • Extends the standard return wizard (stock.return.picking): _prepare_picking_default_values() forces the return picking’s destination to the original picking’s source location.
  • On Odoo 17 the return moves take their destination from the wizard’s “Return Location” field, so the module also overrides _prepare_move_default_values() there — the override is inert on 18/19, where the moves already follow the picking’s destination.
  • Applies to every return created from the wizard (returns, exchanges, partial returns) — chained flows (pick/pack/ship) keep working, only the final destination changes.
  • No views, no data, no stored fields — one small wizard override, safe to install and uninstall at any time.

Compatibility

Tested on Odoo 17, 18 and 19 (Community and Enterprise). Depends only on the standard stock module.
