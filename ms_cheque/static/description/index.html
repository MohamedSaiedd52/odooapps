Overview

  • ✓ Multi-Company Support

Powerful Features

📥

Incoming Cheques

Register cheques from customers, track deposit dates, and manage the bank clearance process with ease.

📤

Outgoing Cheques

Handle payments to vendors via cheques. Manage submission and cashing states automatically.

⚙️

Auto Journaling

Automatically creates Journal Entries for Submission, Deposit, and Cashing, keeping your accounts balanced.

The Workflow

1
Draft Phase

Fill in cheque details (number, date, amount, partner). Uses automatic sequences for tracking.

2
Submission

Submitting a cheque triggers the first journal entry, moving funds to a transitional "Registered" account.

3
Deposit & Cashing

Confirm when a cheque is deposited in the bank or cashed. Odoo handles the account movements automatically.

4
Cancel / Return

Support for cancelling cheques or handling returns with automatic reversal of journal entries.
