POS Analytic Distribution

Seamlessly unite your Point of Sale operations with Odoo's modern Analytic Accounting. Assign, Track, and Analyze with precision.

Odoo 19+ Ready JSON Distribution Community & Enterprise Multi-Session Support

Why This Module?

Bridging the gap between fast-paced POS sales and detailed financial analytics.

Odoo 19 introduced a powerful JSON-based analytic distribution system. However, connecting this system to Point of Sale sessions can be complex.

This module automates the entire flow: configure an analytic account on your POS, and every order automatically inherits the correct distribution tags. When the session closes, your Journal Entries are perfectly tagged—no manual work required.

Solves Common Pain Points:

  • Untracked POS revenue in analytic reports.
  • Manual journal entry adjustments after closing sessions.
  • Inability to separate sales by branch or department automatically.

Key Features

Designed for simplicity and power.

Easy Configuration

Set a default Analytic Account directly in your POS Settings. Configure once, run forever.

Automatic Inheritance

Sessions and Orders automatically inherit the configuration. Zero cashier intervention needed.

Accounting Integration

Seamlessly writes to the Odoo 19+ analytic_distribution JSON field on Journal Items.

How It Works

A simple, linear workflow from setup to reporting.

1 Define Analysis Scope

Navigate to Point of Sale > Configuration > Settings.

Here you can select the specific Analytic Account (e.g., "Branch A", "Retail Department") that should be associated with this Point of Sale.

Enables "Profit Center" tracking per terminal.

2 Business as Usual

Open your POS session and start selling. There are no extra popups or fields for the cashier to fill out.

The system works silently in the background, attaching your pre-configured analytic tags to every order line created.

You can verify this by checking the POS Order backend view.

3 Automated Accounting

When the session is closed and posted, the generated Journal Items will have the Analytic Distribution field populated.

This data flows directly into your Profit & Loss and Analytic Reports.

The module leverages strict inheritance to ensure data integrity.

Data Flow Model
  • pos.config (Setup)
  • pos.session (Runtime)
  • account.move.line (Result)
