Overview

This module bridges the gap between Odoo's Point of Sale and the modern Analytic Distribution system. Every order and session entry automatically inherits the correct analytic tags defined in your POS settings, ensuring precise financial reporting with zero manual work.

Key Features

Simple Config

Set default analytic accounts per POS config. Configure once.

Auto-Inheritance

Sessions and orders inherit analytic tags automatically.

Analytic Reports

Full visibility in Profit & Loss and analytic reports.

How It Works

A streamlined, automated workflow in 3 simple steps

1 Configure POS Settings

Action: Go to Point of Sale > Configuration > Settings and select the Analytic Account (e.g., "Branch A"). This account will be applied to all future sessions and orders.

2 Process Orders

Action: The cashier processes sales normally. Behind the scenes, the system stamps the Analytic Account onto the POS Order. You can verify this in the backend Order view.

3 Verify Accounting

Result: After the session closes, check the Journal Items. The Analytic Distribution (JSON) field is correctly populated with 100% distribution.
