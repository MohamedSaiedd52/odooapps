Key Features

All restrictions are enforced with security record rules at the database level not just hidden in the UI

Warehouse restriction

Each user only sees the warehouses assigned to them all other warehouses and their transfers disappear completely.

 Block specific stock locations

Choose locations (shelves / zones) a user must not see they never appear in any selection list.
Operation type restriction

Define the operation types allowed per user: receipts, deliveries, internal transfers, manufacturing...

 Real multi-warehouse security

Perfect for multi-branch companies: each team works only inside its own warehouse while managers see everything.

Step-by-step Guide

1 Log in as an administrator

Sign in to Odoo with an account that has Administrator access on the Inventory app so you can configure the module.

2 Install the module from Apps

Open the Apps menu, remove the "Apps" filter, search for Stock Location Restrictions and click Activate to install it.

3 Enable the feature in Inventory settings

Go to Inventory Configuration Settings. Make sure Storage Locations is enabled first, then turn on Restrict Stock Warehouse and click Save. When enabled, the current user is automatically added to all warehouses so they are never locked out.

4 Assign allowed users on each warehouse

Open Inventory Configuration Warehouses and select a warehouse. A new Warehouse Allowed users tab appears add the users allowed to see this warehouse, and enable Restrict Stock Location if you also want to restrict locations inside it. The Restrict location for User button jumps straight to the users list to fine-tune their locations.

5 Choose the allowed operation types per user

Go to Settings Users and open a user. In the Access Rights tab you will find the Inventory Restrictions section use the Allowed Picking Types field to define which operation types the user can work with (e.g. receipts and deliveries only).

6 Define the restricted locations for the user

On the same user form, the Restricted Location tab shows the Allowed Warehouse list and lets you pick Restricted Locations locations that will never be visible to this user on any screen.

7 The result: what a restricted user sees

When the restricted user opens the Inventory app, they only see the operation types of their allowed warehouse (WH) the second branch warehouse (WH2) and all of its transfers are completely hidden, as if they don't exist.

8 The result: restricted locations never appear

When creating a transfer and searching the Source Location field, the user only gets the allowed location Shelf A the restricted location Shelf B never shows up in the list.

How does it work technically?

  • Adds a Restrict Warehouse for Users security group, activated from the Inventory settings.
  • Applies record rules (ir.rule) on stock.warehouse, stock.location, stock.picking and stock.picking.type.
  • Stock Managers always keep full visibility of all operation types.
  • Restrictions are enforced at the ORM database level, so they cover the UI, reports and API calls alike.
