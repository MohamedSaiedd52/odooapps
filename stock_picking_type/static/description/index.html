Step 1 — Enable Warehouse Restriction

Go to Inventory → Configuration → Settings, enable Restrict Stock Warehouse and click Save. Restrictions apply to users with the Stock User role, not Inventory Manager.

Step 2 — Assign Allowed Users per Warehouse

Open each warehouse and use the Warehouse Allowed users tab to define who can access it. Users see only the warehouses they are assigned to.

Step 3 — Allowed Warehouses & Restricted Locations per User

On the user form, the Restricted Location tab defines the warehouses the user may work in and the stock locations that will be completely hidden from them. Enforced through record rules inside the module.
